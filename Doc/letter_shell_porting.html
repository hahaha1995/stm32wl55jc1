Letter Shell 移植步骤 · 可视化指南

STM32WL55JC1 (CM4) · FreeRTOS · LPUART1 @ PA2/PA3 · 115200

STEP 0 / 10 从零接入 Letter Shell 的完整流程
letter-shell 源码/配置 移植层 Platform/Shell CubeMX 生成代码接入 构建与链接 完成/验证

核心文件

  • 移植层：`Platform/Shell/shell_port.c`（读写 + 任务 + bootloader 跳转）
  • 配置头：`letter-shell/src/shell_cfg.h`（功能开关集中地）
  • 命令：`Platform/Shell/shell_cmd_user.c`（SHELL_EXPORT_CMD）

三个易错点

  • VCP 引脚：NUCLEO-WL55JC1 = LPUART1 @ PA2/PA3 (AF8)，不是 PC0/PC1
  • 链接脚本必须 KEEP(.shellCommand) 并定义 `_shell_command_start/end`
  • `SHELL_DEFAULT_USER` 找不到用户 → `shellSetUser(NULL)` 空指针 HardFault

移植层默认参数

  • RX 环形缓冲 256 B / 编辑缓冲 512 B / shell 任务栈 4 KB
  • shell 任务优先级 `tskIDLE_PRIORITY + 1`，静态 TCB 零堆分配
  • TX 阻塞 100 ms 超时；RX 单字节中断逐字节入队

使用提示

  • 串口 115200 / 8N1，上电出现 `letter:/$ ` 即成功
  • `help` 查看命令；`download` 进入 ROM bootloader 烧录
  • CubeMX 重新生成后记得补 `ShellInit()` 与中断使能
